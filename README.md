# Suman Jampany — Real Estate Website

A responsive, mobile-friendly website for Suman Jampany, licensed real estate agent.

## Pages

| Page | Description |
|---|---|
| `index.html` | Homepage with hero, services, featured listings, testimonials |
| `listings.html` | Property listings with filter by type, beds, and price |
| `about.html` | Agent bio, stats, and core values |
| `contact.html` | Contact form and office information |

## Structure

```
suman-realtor-website/
```
